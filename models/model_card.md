## Model Summary
This model is a supervised binary image classification component designed to distinguish between natural images and AI generated images. Given an input image, the model predicts whether the image is real or AI-generated and provides a confidence score.

## Model Details

### Model Description

The proposed component performs binary image classification for the detection of AI generated images. The model is trained using the CIFAKE dataset, which contains balanced real and fake image classes.

The objective is to identify patterns that makes it able to discern naturally occurring images from images generated by artificial intelligence. The output consists of a binary classification and a confidence score indicating the model's confidence in its prediction.

## Uses

<!-- Address questions around how the model is intended to be used, including the foreseeable users of the model and those affected by the model. -->

### Direct Use

The model is intended to classify an input image as either Natural or AI Generated. It can be used as a computer vision component in applications that require an initial assessment of image authenticity.

The model provides:

A binary prediction: Real or AI Generated.
A confidence score associated with the prediction.

### Out-of-Scope Use

The model should not be used as the sole basis for high-stakes decisions concerning the authenticity of an image.

It should not be assumed that the model can reliably detect images generated by every generative AI system. The model may perform differently on images generated using models, resolutions or any other image modification technique that are not represented in the training data.

## Bias, Risks, and Limitations

The primary limitation of this model is that the training data is based on the CIFAKE dataset. CIFAKE has real images from CIFAR-10 and synthetic images generated using Stable Diffusion 1.4. The model could learn characteristics from this particular dataset and generation process instead of the general properties that distinguish all real images from all AI generated images.

The dataset consists of small 32 × 32 images and covers ten image classes. This could limit the model's ability to generalize to high-resolution images that differ from CIFAKE.

The model may also be sensitive to multiple transformations of the images.

The model could produce confident but incorrect predictions when presented with images generated by AI systems that use techniques different from those in the training dataset.

### Recommendations

Users should treat the model's prediction as an indication rather than definitive evidence of image authenticity.

Predictions should be accompanied by the model's confidence score and, whenever possible, reviewed by a human. For applications requiring high reliability, the model should be evaluated on additional datasets containing images from multiple generative models and real-world image sources.

Performance should also be evaluated under common image transformations such as resizing, JPEG compression, cropping, and other forms of post-processing.

### Training Data

The model is trained using the CIFAKE: Real and AI-Generated Synthetic Images dataset.

CIFAKE contains 120,000 images divided into two balanced classes:

REAL: 60,000 real images collected from the CIFAR-10 dataset.
FAKE: 60,000 AI-generated synthetic images generated using Stable Diffusion 1.4.
Training set: 100,000 images, consisting of 50,000 REAL and 50,000 FAKE images.
Testing set: 20,000 images, consisting of 10,000 REAL and 10,000 FAKE images.

The images are 32 × 32 RGB images and represent ten semantic categories corresponding to the CIFAR-10 classes.

Dataset source:

https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images
